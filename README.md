# CapsuleControl — Гайд по проекту

## Что это такое

**CapsuleControl** — Windows-приложение (.NET 8, WinForms) для управления переговорной капсулой. Система считывает QR-код пользователя, валидирует его и через Modbus TCP включает/выключает реле (дверь/замок капсулы). Таймер отсчитывает оставшееся время сессии и автоматически завершает её.

---

## Архитектура

```
Form1 (UI + точка входа)
 ├── GlobalKeyboardHook  — перехват ввода QR-сканера
 ├── CapsuleService      — бизнес-логика сессий
 │    ├── QRValidator    — декодирование и проверка QR
 │    └── RelayController — управление реле по Modbus TCP
 └── CustomFont          — загрузка шрифта Max Sans
```

Зависимостей между слоями нет — каждый компонент принимает зависимости через конструктор.

## Компоненты

### `Program.cs`
Стандартная точка входа WinForms. Инициализирует конфигурацию и запускает `Form1`.

---

### `Form1.cs`
Главная форма приложения.

**Константы:**
```csharp
private const string RELAY_IP = "192.168.1.200";
```
IP-адрес Modbus-устройства зашит в коде.

**UI:**
- Фон `#0A0A0A` (почти чёрный), фоновое изображение из ресурсов (`Resources.bg`)
- Два лейбла таймера (`lblTimerL`, `lblTimerR`) шрифт **Max Sans Medium 185pt** — отображают `MM` и `SS` раздельно
- `lblStatus` — строка статуса (скрыта по умолчанию), Segoe UI 24pt
- Разрешение формы: **1280×720**, без рамки, по центру экрана

**Таймер `timer1` (интервал 1 сек):**
Читает 8 цифровых входов с реле. Если любой вход активен и сессии нет — включает реле (`flagAction = true`). Когда все входы погасли и сессия не активна — выключает реле.

**Метод `UpdateUI(string status, string timerText)`:**
Принимает строку вида `"MM:SS"`, разбивает по символу `:` и отдаёт в левый и правый лейблы.

---

### `GlobalKeyboardHook.cs`
Глобальный перехватчик клавиатуры через WinAPI (`SetWindowsHookEx`, `WH_KEYBOARD_LL = 13`).

**Логика:**
1. Накапливает символы в буфер `_buffer`
2. При каждом символе фиксирует время `_lastCharTime`
3. При нажатии `Enter`:
   - Если с последнего символа прошло **≤ 4 секунд** — считает буфер QR-кодом и вызывает `Form1.ProcessQRCode()`
   - Если прошло больше — буфер сбрасывается (ввод с клавиатуры пользователя игнорируется)

> Это стандартный способ работы с USB QR-сканерами: они эмулируют клавиатуру и вводят строку очень быстро, завершая `Enter`.

**Поддерживаемые символы:** A–Z, 0–9, цифровая клавиатура, `-`, `.`, `,`, `/` и их shift-варианты.

---

### `QRValidator.cs`
Декодирует и проверяет QR-строку.

**Алгоритм декодирования:**
1. URL-safe Base64 → обычный Base64 (замена `-`→`+`, `_`→`/`, добавление `=` до кратности 4)
2. XOR-расшифровка: `byte[i] ^= (i * 7 + 13)`
3. Разбивка UTF-8 строки по `|` на 4 части: `[capsuleId|isExtension|unixTimestamp|salt]`
4. Проверка соли: значение должно совпасть с `"spief-2026"`
5. Возврат `SessionData` при успехе, `null` при ошибке

**Структура QR-payload (до шифрования):**
```
{capsuleId}|{isExtension}|{unixTimestampSeconds}|spief-2026
```

---

### `SessionData.cs`
Простая модель данных сессии:

| Поле | Тип | Описание |
|------|-----|----------|
| `Capsule` | `int` | ID капсулы из QR |
| `StartTime` | `DateTime` | Время начала из QR (Unix timestamp → local) |
| `IsExtension` | `int` | Флаг продления сессии |
| `EndTime` | `DateTime` | Рассчитывается при старте |

---

### `CapsuleService.cs`
Основная бизнес-логика.

**Поля:**
```csharp
private int sessiontime = 25; // длительность сессии в минутах
private List<string> disabelKey; // уже использованные QR-коды (одноразовые)
```

**Метод `ProcessQR(string qrText)`:**
1. Проверяет, не использован ли QR (`disabelKey`)
2. Валидирует через `QRValidator`
3. Проверяет, что дата в QR совпадает с **сегодняшней датой** (день и месяц)
4. Считает `num = (StartTime - now).TotalSeconds` — секунды до начала. Если `num + 25*60 < 1` — время вышло, QR блокируется
5. `EndTime = StartTime + 25 минут`
6. QR добавляется в `disabelKey` (одноразовый)
7. Включает реле, запускает таймер обратного отсчёта

**Метод `EndCurrentSession()`:**
Останавливает таймер, выключает реле, сбрасывает `_currentSession`, обновляет UI в `"00:00"`.

> **Важно:** QR действителен только в день выдачи (проверяется день и месяц, но не год).

---

### `RelayController.cs`
Управление реле через **Modbus TCP** (библиотека NModbus).

| Метод | Что делает |
|-------|-----------|
| `StartSession()` | `WriteSingleCoil(unit=1, address=0, true)` — включает реле 0 |
| `EndSession()` | `WriteSingleCoil(unit=1, address=0, false)` — выключает реле 0 |
| `SetRelay(channel, state)` | Универсальная запись любого канала |
| `ReadDigitalVal()` | Читает 8 дискретных входов (unit=1, addr=0) |

**Подключение:** TCP на `192.168.1.200:502` (стандартный порт Modbus). При ошибке подключения `_isConnected = false` и все операции молча игнорируются.

---

### `CustomFont.cs`
Загружает TTF-файл в `PrivateFontCollection` и предоставляет метод `GetFont(size, style)`. Используется для загрузки шрифта **Max Sans** из папки `TTF/`.

## Сетевые требования

- Modbus TCP устройство (реле) должно быть доступно по адресу **`192.168.1.200:502`**
- Unit ID устройства: **1**
- Канал реле: **0** (coil address 0)
- Дискретные входы: адреса **0–7** (8 каналов)

## Формат QR-кода

QR-код — это URL-safe Base64 строка. После декодирования и XOR-расшифровки (`byte[i] ^= i*7+13`) содержит:

```
{capsuleId}|{isExtension}|{unixTimestamp}|spief-2026
```

**Пример генерации QR на Python:**
```python
import base64, time

def make_qr(capsule_id: int, is_extension: int, start_unix: int) -> str:
    salt = "spief-2026"
    payload = f"{capsule_id}|{is_extension}|{start_unix}|{salt}"
    raw = payload.encode("utf-8")
    xored = bytes([b ^ (i * 7 + 13) for i, b in enumerate(raw)])
    b64 = base64.b64encode(xored).decode()
    return b64.replace('+', '-').replace('/', '_').rstrip('=')

# Пример: капсула 1, не продление, начало прямо сейчас
print(make_qr(1, 0, int(time.time())))
```

## Поведение системы

```
QR сканирован
    │
    ▼
Уже использован? ──да──▶ игнор
    │нет
    ▼
Валидный формат? ──нет──▶ UI "00:00"
    │да
    ▼
Дата = сегодня? ──нет──▶ игнор
    │да
    ▼
Время не истекло? ──нет──▶ блок QR, игнор
    │да
    ▼
Добавить в disabelKey
Включить реле (канал 0)
Запустить таймер 25 мин
    │
    ▼ (через 25 минут)
Выключить реле
UI → "00:00"
```

## Известные особенности и ограничения

- **Соль захардкожена** (`"spief-2026"`) — при смене мероприятия нужно перекомпилировать
- **IP реле захардкожен** (`192.168.1.200`) — аналогично
- **Длительность сессии** `sessiontime = 25` минут — захардкожена в `CapsuleService`
- **Проверка даты** сравнивает только день и месяц, не год — QR теоретически валиден каждый год в тот же день
- **QR одноразовый** в рамках одного запуска приложения (`disabelKey` хранится в памяти, сбрасывается при перезапуске)
- `lblStatus` скрыт (`Visible = false`) — поле статуса в UI не используется
